# ODIE

Code and experiment records for **Implicit Neural Representations for Gigapixel Images with On-Demand Parameter Allocation and Expert Routing**.
See `scripts/` for experiment entry points, `configs/experiments/` for run lists, `data/prepare_data.py` for data preparation, and `figures/` for plotting; original code is under the [MIT License](LICENSE), with third-party notices in [patches/licenses/](patches/licenses/README.md).
